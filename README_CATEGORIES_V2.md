# Categories V2

Bu sürümde Kategoriler ekranı referans jungle temasına göre genişletildi.

## Yeni özellikler
- 2 sütun telefon / 3 sütun tablet responsive grid
- Kategoriye özel renk ve ilerleme çubuğu
- 0–3 yıldız göstergesi
- Kilitli kategori altyapısı ve gerekli seviye mesajı
- Kart basma animasyonu
- Üst yıldız/elmas HUD
- Ahşap KATEGORİLER başlığı
- Geri butonu Ana Sayfa sekmesine bağlandı
- Her kategori için ayrı 5 soruluk quiz veri seti
- Quiz üstünde seçilen kategori adı gösteriliyor
- JungleBackground `sky` varyantı düzeltildi

Akış: Ana Sayfa → Kategoriler → Seçilen kategori Quiz → Sonuç
