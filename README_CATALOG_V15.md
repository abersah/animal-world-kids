# Animal World Kids – V15 Büyük Katalog

V15 koleksiyonu 210 hayvan kaydına ölçekler. Keşif & Koleksiyon ekranında gerçek zamanlı isim araması, kategori filtresi (Tümü, Memeliler, Kuşlar, Balıklar, Sürüngenler, Böcekler, Diğerleri, Dinozorlar) ve mevcut Öğrendim/Favori/Kilitli filtreleri birlikte çalışır. SliverGrid yalnızca görünür kartları oluşturduğu için büyük katalogda kaydırma daha verimlidir. V14'ün ayrıntılı 29 ansiklopedi kaydı korunmuş, yeni katalog kayıtları içerik altyapısını genişletmek amacıyla temel metadata ile eklenmiştir.
