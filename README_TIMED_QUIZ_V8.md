# V8 — Süreli Quiz

Yeni mod: **SÜRELİ QUIZ**.

- 45 saniyelik geri sayım
- 5 soruluk kategori turu
- doğru seri (combo) sayacı
- cevap hızına göre bonus XP
- son 10 saniyede kırmızı uyarı
- süre biterse otomatik sonuç
- doğru / yanlış cevap geri bildirimi
- Jungle temalı sonuç ve ödül ekranı

Oyun Modunu Seç ekranından `SÜRELİ QUIZ` kartına dokunarak açılır.
