# Flashcards V7

Bu sürümde Flashcards modu açıldı.

## Özellikler
- Kategoriye göre 5 öğrenme kartı
- Karta dokunarak 3D çevirme animasyonu
- Ön yüzde hayvan görseli/emoji
- Arka yüzde hayvan adı ve kısa bilgi
- Önceki / sonraki kart
- Favoriye ekleme
- Öğrendim işareti
- İlerleme göstergesi

Akış: Ana Sayfa → Kategoriler → Oyun Modunu Seç → Flashcards.
