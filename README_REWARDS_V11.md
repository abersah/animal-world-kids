# Animal World Kids V11 — Ödüller ve Günlük Görevler

- Oyun modları kategori içinde kalır.
- Oyun tamamlamak günlük görev ve sandık ilerlemesini artırır.
- 3 oyun sonrası Günün Sandığı açılır.
- Günlük görevler: 5 doğru cevap, 3 hayvan öğren, 1 oyun tamamla.
- Görev ödülleri: XP, yıldız, elmas.
- Flashcards içindeki “öğrendim” aksiyonu Hayvan Kaşifi görevine bağlandı.
- Ana sayfa HUD değerleri GameProgress üzerinden dinamik hale getirildi.
