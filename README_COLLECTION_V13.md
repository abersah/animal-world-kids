# Animal World Kids — V13 Keşif & Koleksiyon

V13, V12 üzerine çocuk odaklı Keşif & Koleksiyon döngüsünü ekler.

## Yeni özellikler
- Profil içinden **Keşif & Koleksiyon** ekranı
- 29 hayvanlık prototip koleksiyon
- Açık hayvanlarda renkli kart, kilitli hayvanlarda siluet + seviye kilidi
- Tümü / Öğrendim / Favori / Kilitli filtreleri
- Hayvan detay kartında yaşam alanı, beslenme türü, kategori ve kısa bilgi
- Favoriye ekleme
- **Öğrendim** işaretleme ve +5 XP
- Flashcards favori/öğrendim işaretleri artık koleksiyonla ortak ilerler
- Seviye atladıkça yeni hayvan açma kutlaması V12 ile devam eder
- Öğrenilen hayvan, seviye kilidi beklemeden koleksiyonda açılabilir

## Oyun akışı
Ana Sayfa → Kategori → Oyun Modu → Oyun → XP/Ödül → Hayvan Aç → Keşif & Koleksiyon

Not: Flutter kaynak paketindeki ilerleme bellekte tutulur. Test APK paketinde favori/öğrenme/koleksiyon ilerlemesi cihazdaki yerel depolamada saklanır.
