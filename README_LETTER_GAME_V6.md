# Animal World — Harf Oyunu V6

V6 ile Harf Oyunu oynanabilir hale getirildi.

- Hayvan emojisi gösterilir.
- Kelimenin bazı harfleri boş bırakılır.
- Çocuk harf havuzundan sıradaki doğru harfi seçer.
- Yanlış seçim kısa kırmızı geri bildirim verir ve hata sayısını artırır.
- Doğru harf boşluğu doldurur.
- 5 kelime sonunda yıldız ve XP sonucu gösterilir.
- Tüm mevcut hayvan kategorileri desteklenir.
