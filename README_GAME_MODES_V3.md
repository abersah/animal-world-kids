# Oyun Modu Seçim Ekranı — V3

Bu sürüm Kategoriler ekranı ile Quiz arasına çocuk dostu jungle temalı Oyun Modu Seçim ekranı ekler.

## Modlar
- Kolay Quiz — aktif
- Resmi Bul — aktif ve quiz akışına bağlı
- 6 Seçenek — Yakında
- Eşleştirme — Yakında
- Harf Oyunu — Yakında
- Flashcards — Yakında

Kategori kartına basıldığında doğrudan quiz yerine Oyun Modu Seç ekranı açılır. Ekranda kategori ilerlemesi, yıldızlar, XP kaynak HUD stili ve 6 renkli mod kartı bulunur.
